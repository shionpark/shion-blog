## 개요

인톡 파트너스의 "반대편"에 해당하는 양면 마켓플레이스의 공급 측 플랫폼입니다. GA(보험대리점)가 보험 설계사 후보자를 검색·구매·온보딩하고 관리하는 전체 흐름을 제공합니다.

## 주요 기여

- **후보자 매칭 시스템**: 16개 필터 기반 검색, M(동기)×P(잠재력)×A(적성) 매칭 스코어로 Platinum/Gold/Silver 등급 분류
- **크레딧 기반 과금**: 건별 크레딧 차감 구매(개별/대량), 카카오페이 단건 충전 + SID 정기결제, 환불 관리
- **7단계 온보딩 파이프라인**: 후보자 구매 → 매칭 → 미팅 스케줄링까지의 전체 워크플로 설계
- **실시간 채팅**: Socket.IO 기반 GA↔관리자 1:1 채팅, 알림톡·Slack 통합
- **파트너스 연동**: 파트너 신청 인바운드 API, 포트폴리오 동기화, 온보딩 상태 동기화

## 시스템 규모

- 35개 DB 모델, 51개 서비스, 28개 컨트롤러
- 배포: main push → Docker/ECR → EC2(SSM) → Prisma migrate → health check
- 어드민 대시보드: GA/후보자/구매/구독/온보딩/요금제/채팅/통계/분석

## 기술적 도전

### 양면 마켓플레이스 상태 동기화
파트너스(수요 측)와 케어(공급 측) 간 상태 동기화가 핵심 과제. 파트너 신청은 파트너스 → 케어 API로 인바운드 처리하고, 온보딩 상태는 파트너스가 30분 간격으로 케어 DB를 폴링하는 구조로 설계했습니다.

### 3자 동의 기반 매칭 분기
3자 동의 여부에 따라 즉시 매칭(true)과 내부 승인 후 예약 매칭(false)으로 분기하는 로직을 구현하여 법적 요건과 비즈니스 로직을 동시에 충족했습니다.
