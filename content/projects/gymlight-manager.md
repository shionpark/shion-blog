다지점 헬스장의 통합 운영 관리 시스템입니다. 회원, 직원, 상품, 출석, 매출 데이터를 하나의 대시보드에서 관리합니다.

## 내가 만든 것

- **권한 로직 통합** — 분산된 권한 체크 로직을 공통 레이어로 추출하여 유지보수 범위 축소
- **조회 시점 분리** — 실시간 조회와 배치 조회를 분리하여 불필요한 렌더링 비용 절감
- **다지점 데이터 통합** — 복수 지점의 회원·매출 데이터를 통합 조회할 수 있는 대시보드 구현

## 권한 로직 통합

본사 관리자, 지점장, 일반 트레이너가 같은 화면을 보지만 할 수 있는 일이 다릅니다. 권한 체크 로직이 컴포넌트마다 흩어져 있어서 새 기능을 추가할 때마다 역할별 접근 여부를 매번 확인해야 했습니다.

역할별 접근 가능한 기능을 선언적으로 정의하고, 컴포넌트가 권한 세부사항을 몰라도 되는 구조로 바꿨습니다. 권한 로직 변경이 한 곳에서 관리되니까 새 역할이 추가되거나 권한 범위가 바뀔 때 수정 범위가 줄었습니다.

## 조회 시점 분리

출석이나 알림처럼 실시간이 필요한 데이터와, 매출 통계나 회원 목록처럼 변경 빈도가 낮은 데이터를 같은 주기로 조회하고 있었습니다. TanStack Query의 `staleTime`과 `refetchInterval`을 데이터 성격별로 다르게 설정해서, 실시간 데이터만 짧은 주기로 갱신하고 나머지는 캐시를 활용하도록 분리했습니다.
